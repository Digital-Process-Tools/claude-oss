Release v0.29.0 gate 3, round 1 audit (token 3e96e2b2f6e6d380), class B finding, non-blocking
(misreports). changelog.d/1250.fixed.md says the new watcher "flags an unexpected write/create/
remove under that directory during a test run" -- but _DirectoryWatcher (tests/root_scratch_
guard.py) detects ONLY the appearance of a name not in its baseline snapshot: a deletion of a
baselined file and a content modification of an existing file are both invisible to it, nothing
compares the baseline listing against the current one or hashes/stats contents. The same fragment
also says the allowlist covers files test_skill_phase_split.py "legitimately plants and removes
there" -- made untrue later in the same delta by commit be6d93c (#1293), whose own docstring says
the watcher is now "dormant rather than live" for that path. Both overclaims fold into CHANGELOG.md
verbatim at the next /oss:changelog run. Worth correcting the fragment's own wording before it
folds, or accepting the drift and noting it lives here instead.
