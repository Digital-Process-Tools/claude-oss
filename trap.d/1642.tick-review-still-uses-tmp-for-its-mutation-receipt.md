Fixing #1642/#1643's mutation-receipt guard on agents/auditor.md, agents/release-auditor.md and
agents/developer/review.md started by copying agents/tick-review.md's own #1622/#1641 pattern
verbatim, including writing the before-snapshot to `/tmp/oss-tick-review-` (PR numbers) `-tree-
before.json`. A spawned oss:auditor reviewing the new code (commit 814a6fcf) found that `/tmp`
contradicts the already-shipped `.claude/jit-context/tools/01-oss/tree-snapshot-compare.md` rule:
"Write the before-snapshot inside the worktree, never a shared scratchpad... has been observed
gone several calls later with no error at any point." The fix (commit 366fd6ca) moved all three
files this issue touches to a worktree-local, relative filename ending in `-before-snapshot.json`
(so `tree_snapshot.SNAPSHOT_ARTIFACT_RE`, #1330, would exclude it even without an explicit
`--before` anchor) plus an instruction to delete the file once compare has run.

`agents/tick-review.md` itself -- the original template this whole mechanism was copied from --
was left untouched, since it belongs to an already-merged, separate pull request (#1622/#1641)
and touching it here would have been scope creep beyond this issue's own blast radius. It still
instructs the same `/tmp` path today, so the exact hazard this fix exists to remove is still live
in the one spawn that runs on every tick's review step (not just per-lane self-review or
per-release audit). Both second-pass review spawns (an Explore reviewer and oss:auditor)
independently flagged this same file as the one place the fix did not reach, converging on it
without being told about each other's finding.

The exact-anchor exclusion path in `tree_snapshot.py`'s `compare` still works correctly for
`tick-review.md`'s `/tmp` path regardless of naming, so this is not a live defect in the sense of
anything currently misreporting -- it is the reliability hazard the jit rule itself already names
(a file in a shared scratchpad observed vanishing mid-run), still present in exactly the file most
frequently exercised. A future fix in `agents/tick-review.md` should mirror the same three changes
made here: move the file inside the worktree, rename it to end in `-before-snapshot.json`, and add
a delete-after-compare instruction -- plus the corresponding budget-row updates in
`scripts/agent_budgets.py` and `CLAUDE.md`'s own table.
