**The floor is ~65k before turn 1** -- `CLAUDE.md` (~24k tokens), `agents/developer.md` (42,116 B),
the jit-context blocks, the brief, the tool schemas. Re-sent on each of 223-314 turns.

**The sharpest mechanical waste is paging a large file through a capped read.** Lane #1528 returned
272,756 B from 18 `supertool read` calls, and SEVEN of them were exactly 20,000 B -- the cap --
walking `scripts/select_issues.py` and `scripts/lane_setup.py` at `:560:`, `:670:`, `:760:`,
`:1240:`, `:1380:`, `lane_setup.py:1370:140`. ~68k tokens to read two files it needed a function
from, held for the remaining ~200 turns. Same shape as #1179's own finding one layer up, and as the
66,441 B of phase-file paging the sub-manager fragment records: the cap is not a warning, it is a
silent window, and a lane that wants the whole file just calls again.

**Reading outside the worktree routes around the cap entirely.** Three of the four lanes read their
own phase files with `python3 -c "print(open('<plugin cache>/oss/0.34.0/agents/developer/report.md')
.read())"` -- 12,236 B and 13,379 B, uncapped, unranged, no receipt -- because `supertool read` is
scoped to the worktree and the plugin cache is not in it. `cwd:PATH` as a prefix op covers this and
nothing told them.

**Residue is 38k-54k tokens per lane with no `thinking` block stored in the transcript.** Same
subtraction as the sub-manager fragment (`output_tokens` minus every visible content block), same
caveat: it is a subtraction, not a reading. Visible text is under 1,700 B per lane; tool_use inputs
are 18k-33k tokens.

Not the cause, measured and ruled out: pytest (15k-30k B total per lane), git, the edits themselves.

Method: for each assistant record sum `input_tokens + cache_read_input_tokens +
cache_creation_input_tokens` for context, `len()` over `tool_use.input` and `tool_result.content`
for the content halves, and attribute each result to the command that produced it by
`tool_use_id`. `loop_cost_report.py` gives the per-kind totals but not the per-source split --
possibly worth a `--by-source` flag there rather than a scratch script each time.
