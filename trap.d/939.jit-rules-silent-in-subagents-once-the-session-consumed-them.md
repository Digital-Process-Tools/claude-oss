# A jit rule the session already consumed is silent for every agent it spawns

Observed 2026-09-03 while weighing whether `agents/developer.md`'s point traps (TOML literal
escapes, the framed heredoc, `batch` needing `op`) could move into jit-context rules and out of the
lane's per-turn floor (#939).

Two probe spawns, `Explore` and `general-purpose`, each ran
`supertool 'read:trap.d/905.jit-probe-payload-form.md'` plus a negative control. In this session the
same call had injected `trap-fragments.md`. Both spawns reported no JIT block and no hook text of
any kind.

First reading: hooks do not run for subagents. Wrong. `.claude/jit-context/.discovery/logs/hooks.log`
carries `pre-path` and `pre-tool (Bash)` lines at both spawns' timestamps, each ending
`(none) [shown:2]`. The hook ran and suppressed the rule as already shown. The plugin's `common.sh`
says why: the shown set is keyed on the `session_id` in the hook payload, and a spawn's tool calls
carry its parent's session id, so parent and every spawn share one set.

What it cost: about ten minutes and, without the log, a wrong conclusion in the opposite direction
from the truth -- "jit rules never reach lanes" versus "jit rules reach a lane only if nothing
earlier in the session matched them", which have different fixes.

What it means for this repository: the scheduler, the sub-manager and every developer lane are one
session. The sub-manager's own board read and the first lane consume whatever they match; later
lanes get nothing. Everything in `.claude/jit-context/*/01-oss/` shipped to a managed repo has the
same property there. `skills/manager/SKILL.md` already delegated the retype-nothing rule to
`tools/01-oss/pr-create-gate.md` on exactly the assumption this breaks. Whether `mode: block` rules
are exempt from the dedup was not measured.

Not decided here: whether this is a jit-context plugin issue (a per-agent shown set, or no dedup
for spawns), or a fact this loop has to design around. Recorded in
`.claude/jit-context/vocabulary/00-manual/jit-rules-and-subagents.md` as measured.
