effect of a verification step) outweighs the value of closing one checklist item from
inside a three-issue lane that is not the maintainer's own controlled session. Recommend
this specific live-fire check be run by the maintainer directly, ideally pointed at a
disposable scratch repository rather than this one, rather than delegated to a developer
