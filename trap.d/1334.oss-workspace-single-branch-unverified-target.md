live, against claude 2.1.261). If that derivation is wrong for another claude version or another
registry key shape, the file's own comment states the consequence: claude "refuses the launch

already run `claude mcp remove oss-channel -s local`, so the fallback is gone.

to registering `oss-channel` if it does not resolve.
