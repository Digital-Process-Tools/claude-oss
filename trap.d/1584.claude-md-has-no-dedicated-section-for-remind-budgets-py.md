# CLAUDE.md has no dedicated section for scripts/remind_budgets.py

An auditor spawned during #1586/#1584's self-review found that `CLAUDE.md` documents
`scripts/agent_budgets.py`, `scripts/skill_phases.py`, `scripts/command_budgets.py` and
`scripts/claude_md_budget.py` each under their own dedicated `##` section with a full
byte-budget table (`## Agent definitions have a size budget`, `## The manager skill is a
spine plus one file per phase`, `## Command files have a size budget too`, `## This file
has a size budget too`), but the new `scripts/remind_budgets.py` this lane's commit adds
has no such section anywhere in `CLAUDE.md` -- only a docstring inside the module itself
and a mention inside `changelog.d/1584.fixed.md`.

The auditor's own first pass over-claimed that the four sibling scripts are listed in
CLAUDE.md's top-level `## Layout` code-fence inventory (the `scripts/oss_config.py ...`
block) -- checked directly and none of the four appear there either; they are documented
only in their own dedicated sections further down the file, which is the actual pattern
`remind_budgets.py` is missing. Confirmed with `grep -c` for each script name against
both the Layout fence and the whole file.

This is exactly the same defect class this file's own "What is not proven yet" section
already names for #1583 ("CLAUDE.md's own Layout inventory still naming a phase file
deleted earlier in this same delta") and routes to `trap.d/` as a non-blocking `misreports`
finding rather than fixing inline -- the same routing applied here, for the same reason:
CLAUDE.md is extremely tight on its own byte budget (41,489/42,000 B after this lane's own
re-baseline, ~1.2% headroom) and a full new `##` section with a 6-row table would need
another ceiling raise this lane did not judge worth making mid-fix for a documentation
completeness gap rather than a correctness one.

Worth deciding at curation time: does `scripts/remind_budgets.py` get the same full
`##`-section-plus-table treatment as its three siblings, or is a one-sentence mention
folded into an existing section (e.g. appended to `## This file has a size budget too`,
since `remind_budgets.py` is arguably closer in spirit to that one -- both are re-baselined
by the same third editing exception, both watch a corpus re-sent on every turn) enough?
