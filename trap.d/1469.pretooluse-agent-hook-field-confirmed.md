Issue #1469's second suggestion asked whether the harness exposes a hook that could refuse an
`Agent(subagent_type: "oss:sub-manager")` spawn from inside an already-running sub-manager, the
same way `scripts/agent_role.py` already refuses a publish call in code. A prior investigation
(#1022 / PR #1034) had found the general PreToolUse-on-Agent mechanism plausible but left the
exact `tool_input` field name unconfirmed, and declined to build the guard on an unverified
mechanism.

Asked a fresh general-purpose research agent (not this lane's own review spawn -- a plain factual
lookup) to check the official docs directly. It found, and cited:

- `code.claude.com/docs/en/agent-sdk/hooks` lists `Agent` explicitly among the built-in tool names a
  `PreToolUse` `matcher` can target (same list as `Bash`, `Write`, `Edit`, ...), and the same
  `hookSpecificOutput.permissionDecision: "deny"` JSON-output path the docs demonstrate for a
  `Write`/`Edit` matcher applies unchanged to an `Agent` matcher.
- `code.claude.com/docs/en/agent-sdk/typescript`'s `AgentInput` type has exactly three fields:
  `description`, `prompt`, `subagent_type` -- so `tool_input.subagent_type` is the field a hook
  script would read to decide whether the spawn being attempted is `"oss:sub-manager"`.

This upgrades PR #1034's "mechanism plausible, field unconfirmed" note to confirmed against the
published SDK type definition. Building the actual guard (a new PreToolUse hook entry in
`hooks/hooks.json` matched on `Agent`, a script reading `agent_role.py`'s existing marker file and
`tool_input.subagent_type`, plus tests, plus the live-fire testing risk #1034 flagged as its reason
for declining) is a real, separately-reviewable change and was left out of this lane on purpose --
this lane's own scope was the doc-only sub-manager.md/tick.md prose fix for #1469's *first*
suggestion, and the issue itself said building the second half was legitimate to leave out if it
turned out to be a larger change. Worth its own follow-up issue rather than silently dropping the
now-answered half of the original question.
