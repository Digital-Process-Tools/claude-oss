# jit-rules-and-subagents.md is now stale after the once-mode flip

Self-review on #1584 (flipping 19 jit-context `remind` rules to `once` now that
`claude-jit-context` 0.10.0 dedupes `once` per reader rather than per session) found that
`.claude/jit-context/vocabulary/00-manual/jit-rules-and-subagents.md` still describes the
old, now-partially-fixed mechanism as current fact: "Dedup is per `session_id`, and a spawn
carries its parent's... A rule the sub-manager's own board read tripped, or the first lane
tripped, reaches no later lane," and "a `mode: remind` rule fires once per session, so it is
a greeting rather than a guard against a habit." A reader hitting this file after #1584 lands
would reasonably conclude the subagent-silence problem is still unaddressed by mode choice,
when the 19 rules it describes have since moved off `remind` and both `changelog.d/1584.fixed.md`
and `changelog.d/1584.fixed.once-mode.md` describe it as resolved (for the 19, not the 45
default-mode files also mentioned by issue 1584's own reopening comment).

Issue 1584's own reopening comment (2026-09-16) explicitly deferred this rewrite: "it needs
rewriting against the new semantics, and it is the document a later session will reach for
when reasoning about any of this -- but it is a separate change with its own argument, and
bundling it here would mix a mechanical flip with a rewrite." So this was known and
deliberately out of scope for the #1584 lane itself, found again independently by a spawned
`Explore` reviewer during self-review.

Also worth folding in if/when this file is rewritten: the same reopening comment notes that
45 rules under `paths/` and `vocabulary/` carry no `mode:` key at all, and per jit-context's
own README that means they default to `once` (not `remind`) -- so they silently changed from
per-session to per-reader dedup the moment 0.10.0 was installed, with nobody flipping
anything. That is itself worth a measurement (does per-reader dedup on a vocabulary/paths
rule change observed behaviour?) separate from this vocabulary file's own rewrite.
