Gate-3 audit (v0.42.0 round 1, range v0.41.0..HEAD). `skills/manager/phases/
release.md` (~lines 50-55, #1681) tells the releaser to feed gate 2 "its
latest review comment's age", but `scripts/release_gate2.py` (#1706) treats an
ABSENT `latest_review_comment_age_minutes` key as `could-not-tell`, and only
an explicit JSON `null` clears a PR with no review comments. A releaser who
omits the key for every backlog PR with no comments turns each of them into
`could-not-tell`, which blocks the release. What would settle it: one sentence
in release.md saying "pass an explicit `null`, never omit the key, when a PR
has no review comment".
