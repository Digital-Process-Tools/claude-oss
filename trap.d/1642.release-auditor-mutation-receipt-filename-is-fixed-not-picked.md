Release audit (v0.38.0..HEAD, round 2) found: `agents/release-auditor.md`'s mutation-receipt
block (added by `a9dd8bc1`, #1642/#1643) says "Pick your own filename for whichever round
this is, never a fixed shared name" and then supplies a template
(`release-auditor-round<1|2>-before-snapshot.json`) that IS a fixed name, varying only by
round number.

Its two siblings in the same delta do not have this contradiction: `agents/auditor.md`
names the snapshot file from the issue/PR numbers or the spawn's own PID, and
`agents/tick-review.md`'s #1622 fix exists specifically because a fixed shared snapshot
path collides between two concurrent spawns reviewing different pull requests at once.

Two release-audit spawns of the same round over one worktree would read each other's
before-snapshot and produce a mutation receipt about the wrong tree. Whether that is a live
collision depends on whether two release-audit spawns can ever run concurrently against one
worktree -- if not, this is prose contradicting itself rather than an active bug, but the
fix (name the file from the dispatch token, which is already unique per spawn) is cheap
either way.

`misreports` (non-blocking, low reach). Confirmed by direct read of `agents/release-auditor.md`
against its own two siblings, not by running the suite.
