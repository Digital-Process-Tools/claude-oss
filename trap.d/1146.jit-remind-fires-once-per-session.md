A `mode: remind` jit rule fires **once per session**, and a long session touching the same file
class repeatedly gets it exactly that once. It is not a guard against a habit; it is a greeting.

Measured 2026-09-06, in a five-hour session:

    .claude/jit-context/.discovery/state/path-shown-<session-id>.txt   (mtime 11:00)
      ...
      md-is-a-manual-not-a-rationale.md      <- 15th and last entry

That rule says a loop markdown file is an operator's manual: state the rule, the call and the states,
and leave out why the rule exists. It was written at ~10:50 and fired at ~11:00. At 12:34 the same
session rewrote `skills/manager/phases/dispatch.md` and `skills/manager/phases/tick-order.md` and
put rationale straight back in -- five clauses of it -- with no reminder, because the rule had been
in the shown set for ninety minutes. The maintainer caught it by eye, not the hook.

Every hook line in between reads `(none) [shown:4]`. **That string means suppressed, not
unmatched** -- the rule matched every one of those edits and was withheld each time.

**Why this is worse than it looks for this repository specifically.** The rules most worth firing
here are the ones about a *habit* -- how to write prose, how to shape a payload, what a third state
is for. A habit is exactly what a single reminder does not fix, and a long autonomous session is
exactly where habits reassert. The rules that survive one showing are the ones about a fact you
either know or do not; the ones about how you write are the ones that need repeating.

Adjacent, same mechanism, already recorded in
`.claude/jit-context/vocabulary/00-manual/jit-rules-and-subagents.md`: a spawned agent inherits its
parent's `session_id`, so scheduler, sub-manager and every lane share one shown set. A rule the
scheduler tripped at 11:00 reaches no lane dispatched after it.

What would actually help is unknown and not proposed here: re-showing on some interval, or a
per-file rather than per-session shown set, both have obvious costs. What is worth recording is the
measurement -- the mechanism is armed, it is documented, and it did not stop the exact mistake it
was written for, in the session that wrote it.
