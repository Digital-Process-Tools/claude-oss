The maintainer skill and the developer brief now say where a defect in the tooling goes when the loop
is running over a project the tooling does not own: to the tooling own trackers, never to the host
project board, whose maintainer cannot patch it. Both documents state that reporting upstream is the
encouraged, ordinary outcome rather than an escalation, and both name the one board the dependency
derivation cannot produce -- the loop own repository, which is also the one that owns the furniture
written into a managed repo.
