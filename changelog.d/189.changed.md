- This repository's own `.supertool.json` loads the `watch` preset and declares the `gh-prs` radar
  tier, so a maintainer session receives pull-request and CI state as it changes instead of polling
  it with a `sleep` loop in the orchestrator's shell. `scripts/scaffold.py`'s `check_radar` had
  reported this repo as `no-tiers` since radar shipped — a session able to receive channel events
  with nothing publishing any — and now returns clean against it. The hand-typed
  `ops.radar.watch_name` is gone with it: a repository name in a tracked file travels into the next
  repository somebody copies that file to, and the name is derived from `.oss.json` instead (#189,
  and #191/#192 for the derivation). Nothing about the `.supertool.json` that `/oss:scaffold` writes
  into a managed repo changes.
