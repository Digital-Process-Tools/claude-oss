- `scripts/tick_handback.py` and `scripts/release_handback.py` gained an optional
  `COST:` field, a free-text one-line self-report of an agent's own token spend
  (from `scripts/agent_cost.py`), the same shape the developer report's own `cost`
  block already gets, extended to the two agent kinds that did not have it: a
  sub-manager and a releaser. It never blocks classification -- a missing or
  duplicated line folds to the same "absent" answer `release_handback.py`'s
  existing optional `GATE:` field already gets on a paused release (#1499).
